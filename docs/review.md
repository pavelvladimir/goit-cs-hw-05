# Перевірка рішення

Під час review 27.10.2026 перевірено обидва завдання, спільні функції, тести,
JSON Schema, допоміжні скрипти та запуск у Rocky Linux.

## Виправлені помилки

- I/O-помилка під час скасування могла замінити `CancelledError` і залишити worker
  чекати в черзі. Тепер помилка логується, а скасування зберігається.
- Шляхи `source` і `SOURCE/nested` обходили перевірку на macOS. Порівняння тепер
  враховує нормалізацію Unicode та ігнорує регістр.
- Журнал із hard link міг змінити інший файл із тим самим inode. Такий журнал відхиляється.
- Числові символи `²`, `Ⅷ`, `½` рахувалися як слова, а комбінувальні знаки могли
  розривати слово. Токенізацію виправлено й доповнено Unicode-прикладами.
- CLI benchmark не приймав `--warmups 0`, хоча функція це підтримувала. Тепер приймає.
- Rocky-runner помилково відхиляв вимкнені тунельні інтерфейси LinuxKit.
  Перевірка тепер враховує стан інтерфейсу; активним може бути лише loopback.

Перші п'ять випадків покриті регресійними тестами. Після виправлення runner
повний прогін у Rocky завершився успішно.

## Відповідність завданню

| Вимога | Реалізація |
| --- | --- |
| Асинхронне читання й копіювання | `anyio.Path`, `await open/read/write` |
| Рекурсія та потрібні функції | `read_folder` обходить дерево, `copy_file` копіює файли |
| Папки за розширеннями | Останнє розширення без урахування регістру, `no_extension` без нього |
| Аргументи й логування | `ArgumentParser`, stderr і необов'язковий файл журналу |
| Завантаження тексту | `download_text`, HTTP(S) |
| MapReduce та багатопотоковість | Map/Combine/Shuffle/Reduce, `ThreadPoolExecutor` |
| Графік найчастіших слів | `visualize_top_words`, горизонтальна діаграма `barh` |
| Читабельність і PEP 8 | Типи, docstrings, Ruff і mypy |

Обидва скрипти запускаються з головного блоку. У сортуванні виклик проходить
через `asyncio.run(sort_files(...))` до `read_folder`; у другому завданні —
від завантаження до MapReduce та графіка.

Коду з конспекту серед матеріалів не було, тому реалізовано класичну схему
MapReduce без твердження про дослівну відповідність. Технічні критерії виконані.
JSON-звіти, benchmark і Rocky-перевірка доповнюють основні завдання.

Завершальний прогін: 187 тестів без помилок і пропусків на macOS та Rocky,
покриття 98,86%. Додатково звірено результати demo, SHA-256 входів Rocky
і дані benchmark. [Логи та результати](verification.md).

Для здачі потрібні публічний репозиторій `goit-cs-hw-05`, архів `ДЗ5_ПІБ.zip`
і посилання на репозиторій у LMS. Це окремі кроки здачі; локальна перевірка
їх не виконує.
