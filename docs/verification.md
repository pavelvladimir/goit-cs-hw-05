# Результати перевірок

Перевірено **27.10.2026** на macOS ARM64 з CPython 3.14.6 і в контейнері
Rocky Linux 10.2 ARM64. Обидва середовища використовували залежності з `uv.lock`.

| Перевірка | Результат |
| --- | --- |
| `make check` на macOS | 170 тестів, без помилок і пропусків |
| `make check-rocky` | 170 тестів, без помилок і пропусків; demo пройшло |
| Покриття з урахуванням гілок | 98,86% на обох платформах; поріг 90% |

У локальному тексті найчастіші слова — `data: 4`, `words: 4`, `python: 3`.
PNG розміром 1500 × 900 перевірено й переглянуто.

Coverage охоплює чотири основні модулі: `async_sorter.py` — 97,92%,
`mapreduce_words.py` — 100%, `common.py` — 98,08%, `report_validation.py` — 100%.
Допоміжні скрипти й тести не входять у цей показник; виконання дочірніх процесів
не додається до покриття батьківського. Реальне вікно `--show` вручну не перевірялося.

Тести охоплюють файли, HTTP, потоки, CLI, помилки доступу, SIGINT, колізії імен
і JSON-звіти. [Опис тестів](development.md#що-перевіряють-тести),
[відповідність завданню](review.md#відповідність-завданню).

## Аудит поточних залежностей

`make audit` виконано **27.10.2026 о 05:51 Europe/Prague (04:51 UTC)**.
`pip-audit 2.10.1` перевірив 66 залежностей через PyPI, включно з JSON Schema
та інструментами розробки. Відомих вразливостей не знайдено, код завершення — `0`.
Lockfile і версії пакетів не змінювалися.

SHA-256 перевіреного `uv.lock`:

```text
1459541272a4f1533dba985d51f364e38603b81410068f50aefface559dc1b43
```

Окремий JSON-експорт із новим порожнім кешем підтвердив результат без пропусків.
Усі 66 пар назва/версія звірено з requirements. Це перевірка Python-пакетів
для macOS ARM64 і Python 3.14.6; Windows-only пакети та системні RPM Rocky
до неї не входять. Після зміни lockfile аудит потрібно повторити.

Збережено [підсумок із датою та SHA-256](audit/audit-summary.json)
і [повний JSON-результат](audit/pip-audit.json). У підсумку шляхи команд замінено
на відносні до кореня проєкту; результати й SHA-256 не змінено. Аудит відображає
стан бази відомих вразливостей на момент перевірки.

та SELinux enforcing цим запуском не перевірені.

## Збережені приклади

[Benchmark](benchmark.md) містить JSON, CSV і графік запуску до додавання
JSON Schema. Його SHA-256 описують стан коду на час вимірювання, до змін
`common.py`, `uv.lock` і поля шляху в benchmark.

[Графік Gutenberg](images/top_words.png) отримано того самого дня до уточнення
Unicode-токенізації: 127 870 слів, 6 824 унікальні. Це приклад попереднього
запуску; актуальний результат залежить від тексту за URL і правил токенізації.
